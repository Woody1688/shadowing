Shadow Loop跟讀機
注意：目前是直接打開檔案（file://），YouTube 會拒絕播放。請把 index.html 上傳到 GitHub Pages 或 Netlify，再用那個網址開啟（見使用說明）。

貼上一支 YouTube 影片，逐句跟讀

  1. 在上方貼上 YouTube 網址，按「載入」。
  2. 匯入字幕：在 YouTube 影片頁按「Shadow Loop 字幕」書籤（設定方式在右側「字幕來源」），或把轉錄稿貼上。
  3. 點任一句子：會自動重複播放，每遍之後留一段停頓讓你跟著說。點句中單字可以查詞、加入生字本。
  4. 想要更自然的斷句、翻譯、文法說明或口音判斷，用「Claude 助手」交給你的 Claude 對話完成。
