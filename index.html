Shadow Loop跟讀機
注意：目前是直接打開檔案（file://），YouTube 會拒絕播放。請把 index.html 上傳到 GitHub Pages，再用那個網址開啟。

貼上一支 YouTube 影片，逐句跟讀

  1. 在上方貼上 YouTube 網址，按「載入」。
  2. 匯入字幕：在 YouTube 影片頁按「Shadow Loop 字幕」書籤（設定方式在右側「字幕來源」）。書籤會抓字幕檔裡的逐字時間，句子切點最準。
  3. 選練習方式：聽後跟說、同步跟讀、延遲跟讀或聽寫。點任一句子就開始。
  4. 好句子按「☆ 收藏」，會集中到「句子本」複習。

方法一：一鍵送字幕（電腦版瀏覽器，最準）

Shadow Loop 字幕

第一次使用：把上面的按鈕「拖曳」到瀏覽器的書籤列。之後在 YouTube 影片頁按這個書籤，它會讀取字幕檔的逐字時間並送到這裡。舊版書籤請刪掉重拖一次。

方法二：手動貼上

YouTube 說明欄 →「顯示轉錄稿」→ 選取時間與文字複製，貼在下方（或在本頁任意處直接 Ctrl+V）。時間只到秒，切點會比較粗略。也可以上傳 .srt / .vtt。
